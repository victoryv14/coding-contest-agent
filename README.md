# coding-contest-agent
A personal AI-powered coding contest intelligence agent that tracks upcoming contests, filters them based on preferences, and sends timely notifications.
## Problem
As a aspiring coding enthusiast I wanted to participate every contest I prefer. But eventually end up forgetting in the busy of daily works. To overcome this I wanted to build a AI personal agent that remainds me about my coding contests and notifies me.
## Goal 
Develop an AI agent that collects the information of different coding contest that will be held in the different platforms like CodeChef, LeetCode, Codeforces, etc.., and gives notification or an alarm like thing on custom time before the contest starts.
